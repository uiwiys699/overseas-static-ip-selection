## 原生、家宽、双 ISP、CMI 到底差在哪

这是整篇文章最值得花时间看的部分。四种 IP 出身直接决定平台怎么识别你，选错了配置再高也没用。

**原生 IP**：IP 注册地和机房物理位置一致，IP 库查出来就是这个国家。日本 IIJ、新加坡、台湾、英国、德国的套餐属于这一类。它解决的是“地区归属正确”的问题，适合需要当地身份登录后台、看当地搜索结果、跑区域服务的场景。

**家宽 IP（Residential）**：IP 归属登记为真实家庭宽带运营商。澳洲节点用的是 EXETEL 家宽，韩国标的是原生家宽。平台风控看到的是一个家庭用户在上网，不是一台服务器在发包，账号关联风险比纯机房 IP 低一档。

**双 ISP**：同一段 IP 同时归属两个运营商，掩盖数据中心痕迹，规避能力比单 ISP 家宽再强一些。WePC 洛杉矶 9929 和 4837 两个美区套餐是这类，跑 TikTok 起号和直播推流的人多数看这两档。

**CMI 线路 IP**：走中国移动国际线路，属性是运营商线路，移动用户延迟最低。它不伪装成当地家庭用户，价值在三网回程质量，适合建站、代理转发、需要低延迟国内访问的场景。

决策规则可以压成一句话：**要骗过平台的风控，选原生或家宽；要让国内访问快，选 CMI；两者都要，就看双 ISP 的美区套餐。** TikTok、跨境电商多账号这类对 IP 属性敏感的业务，优先原生 IP 或家宽 IP；建站、跑代理、做数据采集，CMI 这类线路 IP 更划算。

第三方测评提到，洛杉矶 9929 三网回程强制走联通 AS9929，联通家宽实测下载约 3.5MB/s；香港 CMI 国内访问延迟约 40–60ms；日本 IIJ 三网直连不需要中转。这些是测评转述，不是本文实测，你的本地网络跑出来可能不一样。

## 谁不适合买 WePC

三类人建议直接绕开：

**电信宽带用户。** 除香港和少数优化线路，大部分节点对电信不友好。澳洲墨尔本节点移动、联通直连延迟 180–220ms，电信会绕美国，延迟明显更高，需要自己配中转。你先确认自己常用的是哪家宽带，再看节点。

**需要频繁换 IP 的营销场景。** WePC 换 IP 是收费的，第三方口径约 18 元一次，只有开通 24 小时内出现异常才免费换一次。要批量轮换 IP 做投放或采集，VPS 模式本身就不匹配，按流量计费的代理池更合适。

**需要 Windows 的用户。** 全线默认只提供 Linux，不装 Windows。远程桌面、Windows 专属软件这类需求得另想办法。

反过来，联通和移动宽带用户、做 TikTok 跨境运营的内容团队、需要多地区 IP 的电商运营，是这套产品对得上的场景。

## 常见问题

**要不要实名认证？** 现有资料里没有 WePC 要求实名认证的记录，开通流程如果出现相关提示，按页面要求走即可。

**对本地网络环境有要求吗？** WePC 交付的是 VPS，你用 SSH 或远程工具连上去操作，本地网络是哪家宽带都能连。但本地宽带的运营商会影响你连过去的延迟，电信用户尤其明显。

**能装 Windows 吗？** 不能，默认只提供 Linux 发行版。

**IP 被封了怎么办？** 不在退款范围，付费换 IP，约 18 元一次。开通 24 小时内出现异常可以免费换一次，这个时间窗口要抓住。

**流量超了会停机吗？** 香港 CMI 等线路是达量限速，不停机，但速度会掉下来。
